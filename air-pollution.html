Machine Learning Project

Air Pollution Prediction System

A machine learning-based system that analyzes air pollution data and predicts air quality using pollutant measurements and environmental sensor data.

GitHub

About the Project

The Air Pollution Prediction System was developed to analyze air-quality data and predict pollution levels using machine learning techniques.

The system works with pollutant parameters such as PM2.5, PM10, NO₂, SO₂ and CO. Based on the available data, the system can classify air quality into categories such as Good, Moderate and Poor.

The project also incorporates IoT sensor data to support real-time environmental data collection and analysis.

Key Features

AQI Prediction

Predicts air quality using pollutant and environmental data.

Pollution Classification

Classifies air quality into Good, Moderate and Poor categories.

Pollutant Analysis

Analyzes PM2.5, PM10, NO₂, SO₂ and CO pollutant measurements.

IoT Sensor Data

Uses environmental sensor data as part of the pollution monitoring system.

Data Processing

Processes and prepares pollution data for machine learning models.

Machine Learning

Applies multiple machine learning models to analyze and predict pollution levels.

Python Pandas NumPy Scikit-learn IoT Sensors

Development Process

  • Collected and prepared air pollution data containing multiple pollutant parameters.
  • Used Pandas and NumPy for data manipulation and preprocessing.
  • Analyzed pollution parameters to understand air-quality patterns.
  • Applied different machine learning algorithms for prediction and classification.
  • Compared model performance to identify suitable prediction approaches.
  • Used IoT sensor data as part of the environmental monitoring system.

Project Result

The system achieved approximately 88% accuracy for AQI prediction in the project dataset.

The model can be used to classify air-quality conditions and provide an indication of pollution levels based on the available input parameters.

Challenges & Solutions

One challenge was working with multiple pollutant parameters that can have different ranges and distributions. Data preprocessing and analysis were performed before applying machine learning models.

Another challenge was comparing different classification algorithms. Multiple models were tested to understand their performance on the available pollution dataset.
