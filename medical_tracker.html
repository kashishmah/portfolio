Web Development Project

Medical Tracker

A responsive medical tracking web application designed to help users manage medical information, profiles, appointments, reports and medication reminders in one place.

GitHub Live Demo

About the Project

Medical Tracker is a frontend web application developed to provide users with a simple and organized way to manage important medical information.

The application allows users to manage their profile information, view medical reports, manage appointments and keep track of medicines.

The application also supports multiple profiles under one account, allowing users to manage information for family members such as a child, mother or father.

Key Features

User Login

Users can log in using their email and password to access their medical information.

User Profile

Provides a dedicated profile section where users can manage their personal information.

Multiple Profiles

Allows multiple family profiles such as child, mother and father to be managed under one account.

Medical Reports

Users can access their medical reports through the application.

Appointments

Provides an appointment section for managing and viewing medical appointments.

Medication Tracking

Helps users keep track of their prescribed medicines and medication schedules.

Medication Reminders

Provides notification and reminder functionality for scheduled medications.

Logout

Users can securely log out of their current account from the application.

Responsive Design

The interface is designed to work across desktop, tablet and mobile screen sizes.

Technologies Used

HTML CSS JavaScript LocalStorage

Application Functionality

JavaScript is used to handle user interactions, navigation, profile management, login functionality and dynamic updates within the application.

LocalStorage is used to maintain relevant user and application data within the browser so that information can remain available between page visits.

The application also checks medication schedules and provides reminders when a scheduled medication time is reached.

Development Process

  • Designed the medical dashboard and responsive user interface.
  • Created login and logout functionality using JavaScript.
  • Added a user profile section for managing personal information.
  • Implemented multiple profiles under a single account.
  • Added sections for medical reports, appointments and medications.
  • Implemented medication timing and reminder functionality.
  • Used LocalStorage to maintain application data within the browser.
  • Tested the interface across different screen sizes.

Challenges & Solutions

One challenge was managing different user profiles within the same application. JavaScript logic was used to maintain separate profile information and switch between profiles.

Another challenge was maintaining user data between page navigation and browser sessions. LocalStorage was used to store relevant data locally in the browser.

Implementing medication reminders also required checking scheduled times and triggering notifications when the medication was due.

Creating a consistent responsive interface was handled using CSS layouts, flexible components and responsive design techniques.
